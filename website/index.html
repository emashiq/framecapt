Capture, record, mark up.
All on your own computer.

FrameCapt is a screenshot and screen-recording app for developers, QA engineers and support teams. Press a shortcut, pick a screen, window or region, then copy or save. Nothing is uploaded, ever.

  • Free and open source (GPL-3.0)
  • No account
  • No telemetry
  • Windows + Linux

Download

Pick your system. Each link points at the newest build published on GitHub Releases.

Windows

Recommended

Windows 10 or 11, 64-bit (x64). About 230 MB.

  • Installer (.exe)Per-user install, no admin rights
  • Portable (.zip)Unzip and run, nothing installed

The installer is not code-signed yet, so SmartScreen will warn. See how to install.

Linux

Experimental

x64, X11 session (or XWayland). About 190 to 260 MB.

  • AppImageAny distribution, runs without installing
  • Debian / Ubuntu (.deb)Installs with apt, adds a menu entry

Microphone only (no system audio). Not yet tested on a real Linux desktop. See how to install.

Check your download. Every release ships a SHA256SUMS.txt. Compare it with Get-FileHash .\FrameCapt-Setup-*.exe on Windows or sha256sum FrameCapt-* on Linux before you run anything.

Install

A minute or two on either system.

Windows

  1. Download FrameCapt-Setup-<version>.exe and run it.
  2. SmartScreen says “Windows protected your PC”: click More info, then Run anyway. (This appears because the installer is not signed.)
  3. FrameCapt installs for your user only, into %LOCALAPPDATA%\FrameCapt, and starts. No administrator rights are needed.
  4. Look for it in the Start menu next time, or in the tray near the clock while it runs.

Portable: unzip FrameCapt-win32-x64-*.zip anywhere and run FrameCapt.exe. Uninstall: Settings > Apps > FrameCapt. Your screenshots and recordings stay unless you ask for them to go.

Linux

AppImage, any distribution:

chmod +x FrameCapt-*-x64.AppImage
./FrameCapt-*-x64.AppImage

No FUSE (libfuse2) on your system? Install it (sudo apt install libfuse2t64 on Ubuntu 24.04+) or run with --appimage-extract-and-run.

Debian or Ubuntu package:

sudo apt install ./framecapt_*_amd64.deb
framecapt                  # or use the app menu
sudo apt remove framecapt  # your files stay

Wayland: FrameCapt runs through XWayland; native Wayland windows may show up black.

Your first capture

FrameCapt opens ready to go. There is nothing to sign in to.

  1. Press a shortcut Ctrl Shift 3 for a region, from any app.
  2. Drag a rectangle Resize with the handles, press Enter to capture.
  3. Mark it up Arrows, boxes, text, crop and solid redaction in the editor.
  4. Paste or save It is already on the clipboard. Ctrl S saves a PNG.

Default shortcuts

Action Screenshot Record
Whole screen Ctrl+Shift+1 Ctrl+Shift+5
A window Ctrl+Shift+2 Ctrl+Shift+6
A region Ctrl+Shift+3 Ctrl+Shift+7
All screens (several monitors) Ctrl+Shift+4 Home > Record > All screens
Step guide Ctrl+Shift+8
Pause / resume recording Ctrl+Shift+9
Stop recording Ctrl+Shift+0

Change any of them in Settings > Shortcuts. The full walkthrough is in the user guide.

What it does

Everything runs locally. No cloud, no upload, no sharing links.

Screenshots

Screen, window, region or all monitors at once. PNG or JPEG, straight to the clipboard.

Editor

Crop, arrows, boxes, text and solid redaction that is burned into the saved pixels.

Screen recording

1080p or source resolution, 30 or 60 fps, microphone and system audio, pause and resume.

Record in parallel

Up to three recordings at once, screenshots on any monitor while you record, and extra regions or windows added to a running video.

Meeting capture

Notices Meet, Zoom, Teams and Webex calls and offers to record them, with your screen share. A hidden meeting window is never recorded; its audio is.

Video editor

Trim, cut, blur or redact, crop, add text, images and music. Export MP4, WebM or GIF.

Step guides

Rest the mouse on each step and FrameCapt builds a numbered guide you can export as HTML or video.

Library

Search, sort and folder your captures. Folders are real folders on your disk.
