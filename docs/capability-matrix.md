# Capability matrix

Status values: **Not started**, **Foundation** (scaffolding only), **Implemented**, **Blocked**. "Verified on host?" means actually exercised on the build host, not assumed.

Host used for verification: Windows 11 Pro (10.0.26300), AMD Ryzen 7 7700, 63 GB RAM, interactive desktop, two monitors (3440x1440 at 0,0 and 2560x1440 at 3440,0 per `System.Windows.Forms.Screen`), AMD Radeon + NVIDIA RTX 5070 Ti. Electron 44.5.1.

## Platform support

| Item              | Value                     | Notes                                                                                                                                                      |
| ----------------- | ------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Supported Windows | Windows 10 and later, x64 | Electron 23+ dropped Windows 7, 8 and 8.1; Framelet pins Electron 44. Only Windows 11 was available for testing, so Windows 10 is "expected", not verified |
| Windows arm64     | Not targeted              | The packager config builds x64 only                                                                                                                        |
| macOS / Linux     | Out of scope for the MVP  | Makers are Squirrel (Windows) and ZIP (win32) only                                                                                                         |

## Codecs and export plan

| Item                | Plan                                                                                                                                                                                                                                                 | Status                                                                                                                                                                                                                                                                                                                                             |
| ------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Recording container | WebM through `MediaRecorder`, MIME/codec chosen at runtime with `MediaRecorder.isTypeSupported` (VP9/VP8 and Opus candidates). Nothing is hard-coded                                                                                                 | Implemented (phase 05). The finished WebM in `Videos/Framelet` is also the WebM "export"; "Save a copy as..." copies it through a temp file and a rename                                                                                                                                                                                           |
| Finalization        | FFmpeg `-c copy` remux of the session into a seekable WebM (duration and Cues), probed (video stream, duration > 0) and renamed atomically; the session directory (and `stream.webm`) is then removed. Chunks are not concatenated blindly           | Implemented (phase 06); verified on the host                                                                                                                                                                                                                                                                                                       |
| MP4 export          | Real conversion with a bundled FFmpeg build (libx264 + aac), never an extension rename. The exact FFmpeg source, build options and license must be recorded in third-party notices; codec/patent review is an owner action before commercial release | Implemented (phase 07); verified on the host with a real recording (H.264 + AAC, same duration, fast start, clean decode; cancel and retry keep the original). Detected at startup (libx264 + native aac); without both the UI says MP4 is unavailable and WebM stays the deliverable. Codec/patent review remains an owner action: docs/ffmpeg.md |
